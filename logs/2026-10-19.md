## G01-P-01 · paper/rebuttal · 复习 #2
- 中文：能否请审稿人提供与这一点相关的参考文献？

## G10-P-02 · paper/ablation · 复习 #2
- 中文：这些结果表明，硬件反馈比代码示例更有用。

- 得分：4.0（语义 1.0 · 语法 1.0 · 地道 1.0 · 语域 1.0）
- 更好的说法：These results suggest that hardware feedback is more useful than code examples.
- 备注：much 是加料（中文只说“更”）；代码示例 = code examples（demonstrations 在 few-shot 语境可用，但要复数）；suggest 后保留 that
