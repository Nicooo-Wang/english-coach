## G10-T-03 · airport/delay · 复习 #1
- 中文：前一班晚点了，我们可能会错过转机。
- 作答：the last flight is late, we might miss next flight
- 得分：3.5（语义 1.0 · 语法 0.5 · 地道 1.0 · 语域 1.0）
- 更好的说法：Our first flight is running late, so we might miss our connecting flight.
- 备注：might miss 用对；“前一班”说成 the last flight，容易听成“最后一班”，应为 our first / previous flight；“转机”说成 next flight 还缺冠词，应为 our connecting flight / our connection；晚点用 is running late / is delayed 比 is late 常见

## G01-P-03 · paper/collaboration · 新题
- 中文：实验还没跑完，能不能把截止日期推后几天？
- 作答：The experiment is not finished. Is it? Is there any possible to postpone the deadline?
- 得分：3.5（语义 1.0 · 语法 0.5 · 地道 1.0 · 语域 1.0）
- 更好的说法：The experiment hasn't finished yet. Would it be possible to extend the deadline by a few days?
- 备注：中间的 Is it? 按口语改口处理，不扣分；“能不能”说成 Is there any possible to（possible 是形容词，不能放在 any 后面当名词；换成 Is there any possibility to 也是摸底时记下的中式说法），没用目标表达 Would it be possible to；漏译“几天”（by a few days）；“还没”少了 yet；postpone the deadline 可以，extend / push back 更常见

## G03-T-01 · transport/traffic · 新题
- 中文：要是早知道会堵车，我们就坐地铁去机场了。
- 作答：If I know we will be blocked, we definitely take subway to go to the airport.
- 得分：2.5（语义 1.0 · 语法 0.0 · 地道 0.5 · 语域 1.0）
- 更好的说法：If I'd known there would be traffic, we would have taken the subway to the airport.
- 备注：虚拟语气完全没用（If I know …, we take …），和摸底第 15 题是同一个问题，应为 If I'd known …, we would have taken …；“堵车”说成 be blocked（= 被挡住、封路），应为 there would be traffic / get stuck in traffic；“就”加料成 definitely；subway 缺 the；take the subway to go to 里的 to go 多余
