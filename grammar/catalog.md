# 语法点清单（草案，待摸底后定稿）

每个语法点在旅行（T）和论文（P）两类场景各出 5 题。下面列出的是覆盖面，顺序和取舍会根据摸底结果调整。

| ID | 语法点 | 旅行场景示例 | 论文场景示例 |
|---|---|---|---|
| G01 | 委婉请求与许可（Would it be possible to / Would you mind / I was wondering if） | 提前入住、延迟退房、换房 | 请审稿人澄清、请求补充数据 |
| G02 | 条件句（If … / Unless / As long as / Provided that） | 改签条件、免税额度 | 方法的适用条件、实验设置 |
| G03 | 虚拟语气（would have / If I had / I wish） | 航班延误后的抱怨与假设 | 反事实分析、消融实验的假设 |
| G04 | 定语从句与关系副词（which / where / whereby） | 描述丢失的行李、所订的房型 | 描述模型组件、数据集 |
| G05 | 分词短语（-ing / -ed 作状语或定语） | 行程描述 | 方法描述（Given …, Built on …） |
| G06 | 被动语态 | 行李被损坏、预订被取消 | 实验流程、数据处理 |
| G07 | 名词化（make a decision / the introduction of） | 正式投诉 | 学术书面表达 |
| G08 | 对比与让步（whereas / while / despite / although） | 比较房型、比较航班 | 与基线方法比较 |
| G09 | 因果表达（due to / result in / lead to / thus） | 延误原因、退款理由 | 结果解释、原因分析 |
| G10 | Hedging 与情态（may / might / is likely to / suggest） | 不确定的请求 | 谨慎陈述结论 |
| G11 | 强调句与倒装（It is … that / Not only … but also / Only when） | 强调诉求 | 强调贡献 |
| G12 | 形式主语（It is worth noting that / It turns out that） | 说明情况 | 引出观点 |
| G13 | 比较级与程度（far more / significantly / by a margin of） | 价格比较 | 性能提升描述 |
| G14 | 时态与完成体（have been / had already / will have） | 已等待多久、已付款 | 已有工作、本文贡献 |
| G15 | 目的与结果（so that / in order to / such that） | 安排行程 | 设计动机 |
| G16 | 名词性从句（what / whether / how 引导） | 询问是否包含早餐 | 研究问题陈述 |
| G17 | 数量与范围（up to / at most / a range of / roughly） | 免税额度、行李重量 | 参数规模、数据规模 |
| G18 | 转述与引用（according to / as reported in / X argues that） | 转述前台说法 | 引用相关工作 |
| G19 | 补充与递进（in addition / moreover / not to mention） | 补充需求 | 补充实验 |
| G20 | 礼貌拒绝与协商（I'm afraid / I'd rather / Would it be okay if） | 拒绝升级收费、协商价格 | 回复审稿意见（rebuttal） |
